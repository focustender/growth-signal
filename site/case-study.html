Trade Signal

One system built to show how a Lifecycle Growth & Analytics Manager and an AI-First UI/UX Designer would actually hand work back and forth at Fireclay — not two separate portfolio pieces, but a single loop: a real friction point found in the data motivates a real interface change, and a new on-site feature closes the loop by feeding a new signal back into the data.

Lifecycle Growth & Analytics Manager AI-First UI/UX Designer — Shopify

The finding that started it

From a 3,200-customer synthetic dataset modeled on Fireclay's own funnel language (interest → sample → project → purchase → repeat → advocacy), analyzed directly with Claude Code against a local SQLite store.

73%

of trade leads acquired at trade shows who request exactly one sample never advance to a project upload or purchase — more than double the stall rate of leads acquired through email capture (33%). The single strongest predictor of eventual purchase in this segment is requesting a second sample, which trade-show leads do at less than half the rate of the trade segment overall.

How the three pieces close the loop

The friction finding motivates the interface change. The interface change ships a new feature. The new feature generates a new signal back into the same dataset.
